Get started

Install it, then give it a model.

JimmyHQ runs from its source code today. It takes a few minutes. Nothing goes to a hosted model until you add one. For more depth, each step links to the guide in the repository.

  1. Have uv and Node.js

    You need uv, which installs Python and JimmyHQ's packages, and Node.js 22 or later, which builds the web app once. Both are free. JimmyHQ's checks run on macOS, Linux and Windows.

  2. Install and run

    git clone {{repo}}.git
cd {{repo_name}}
uv sync
cd web && npm install && npm run build && cd ..
uv run jimmyhq run

    Then open http://127.0.0.1:8440 in your browser and create your owner account. JimmyHQ listens on your own machine only. To start it at login, run uv run jimmyhq service install.

  3. Choose a model

    Most of what JimmyHQ does needs a language model. Under Settings, Models, add one: a server on this computer such as {{providers:local}}, a model on another computer you own, or a hosted provider ({{providers:hosted}}) with your own key. Then give each role its model.

    The models guide

  4. Add an app

    Open Apps. Under Made by the JimmyHQ project, each app has its own Install button. You see what it may do and say yes, and it appears in the sidebar. Every app that sends something out starts in Practice, where it records what it would have done and sends nothing. Switching out of Practice is a setting you change yourself.

    First steps

  5. Turn on backups

    Under Settings, Backups, choose a folder, ideally on another drive, and optionally a second one. Backups are off until you do. Each backup is checked as it is made, and the newest is tested in full every week. A backup holds what signs you in and your keys, so keep it somewhere only you can read.

    uv run jimmyhq backup list
uv run jimmyhq backup verify <backup folder>
uv run jimmyhq backup restore <backup folder>

    Back up and move your data

  6. Reach it from your phone, if you want to

    Settings, Access has a card that puts JimmyHQ on your own private network with Tailscale, and says exactly what it will run before it runs it. It never opens JimmyHQ to the public internet.

    Reaching JimmyHQ from your other devices

Good to know

A few commands you may need.

Where your data is

One folder, outside the code. This prints it. Set JIMMYHQ_DATA to use another.

uv run jimmyhq data-dir

A forgotten password

There is no recovery by email. On the computer JimmyHQ runs on, this asks for a new one and signs out every browser.

uv run jimmyhq owner set-password

Settings as files

Every setting can be listed, changed, exported and imported from a terminal. A profile leaves out what is personal to you.

uv run jimmyhq settings list --changed
uv run jimmyhq settings export --profile --changed -o my-profile.json
uv run jimmyhq settings import my-profile.json --dry-run
